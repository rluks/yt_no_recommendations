Tampermonkey/Greasemonkey userscript that removes the list of suggested videos from YouTube.

Install: with Tampermonkey or Greasemonkey installed, open [the raw script](https://raw.githubusercontent.com/rluks/yt_no_recommendations/master/yt%20no%20recommendations.user.js).

More: [Binge-watching prevention on YouTube](https://romanluks.eu/blog/how-to-stop-yourself-from-binge-watching-videos-on-youtube/)
